# Terrance Tan Ee Thern - Personal Portfolio

A single-page, interactive personal portfolio website showcasing work in semiconductor analytics, AI agent orchestration, and business intelligence. 

The site features a unique dual-mode interface, allowing visitors to toggle between a fun, personality-driven mode and a traditional corporate layout.

## ✨ Features

* **Dual-Mode Interface:** A built-in toggle switch transitions the entire site between "delulu" (casual, Gen-Z style with vibrant colors and emojis) and "serious" (clean, corporate, muted palette) modes.
* **Interactive UI/UX:** Features a custom cursor, cursor-following emoji trails, and intersection observer-based scroll animations.
* **Easter Eggs:** Typing the secret `ttet` keyboard shortcut triggers a hidden animation and notification.
* **Audio Feedback:** Includes lightweight, synthesized audio effects for button clicks and interactions (with a mute toggle).
* **Responsive Design:** Fully mobile-optimized layout utilizing CSS Grid and Flexbox.
* **Zero Dependencies:** Built entirely with raw HTML, CSS, and Vanilla JavaScript. No external frameworks or libraries required.

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and accessibility (ARIA labels).
* **CSS3:** Custom properties (variables) for theming, keyframe animations, backdrop filters, and responsive media queries.
* **Vanilla JavaScript (ES6+):** DOM manipulation, event delegation, audio context synthesis, and Intersection Observer API for scroll reveals.

## 🚀 Getting Started

Since the project is a single, self-contained file, no complex build tools or package managers are required.

1. Clone or download the repository.
2. Ensure the main file is named `index.html`.
3. Double-click `index.html` to open it in any modern web browser (Chrome, Edge, Firefox, Safari).
